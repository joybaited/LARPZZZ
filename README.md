# LARPZZZ

Design-led site with 3D.

## Setup

```bash
git clone https://github.com/amalbycia/LARPZZZ.git
cd LARPZZZ
npm install
npm run dev
```

## Read this first

**[docs/COLLABORATION.md](docs/COLLABORATION.md)** — how we work on this
together without causing conflicts. Read it before your first push.

The short version: nothing goes directly on `main`, never both edit the same
file at once, and `git pull --rebase origin main` before every push.

Next.js (App Router) · TypeScript · Tailwind v4 · three.js / react-three-fiber
